# Robotic Arm

<img width="632" height="844" alt="image" src="https://github.com/user-attachments/assets/cf582144-f20f-43b2-9701-b793493c86e1" />

A small robotic arm I built to improve my electronics skills and to get into CAD and 3D modeling. I recently got a 3D printer, so this is the first project where I designed and printed the parts myself.

The arm is driven by MG90S micro servos (from AliExpress) and controlled from a web UI served by the ESP32. The claw is not my design, it comes from mobiobi's robotic arm on MakerWorld. Credits for the claw go to him.

All STL files I designed are in the [3dModels](3dModels/) folder (some may still be added later).
